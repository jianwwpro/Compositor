# Compositor

Adobe Photoshop 太贵，而 GIMP 这类工具又不够顺手，无法让我保持专注。这就是我开发 Compositor 的原因。

我的目标是打造一款完全免费、开源的全功能图像编辑器。我以前用 Photoshop 做合成和后期处理，所以 Compositor 就是围绕这一工作流构建的——提供制作像素级完美成片所需的全部工具。

因为它是开源的，你可以下载 Xcode 工程，添加、删除或修改任意功能来适配你的工作流。

## 安装

### 下载
从 [robbietilton.com/compositor](https://robbietilton.com/compositor) 获取 Compositor，或直接从 [GitHub Releases](https://github.com/robbietilton/Compositor/releases/latest) 下载最新版本。

### Homebrew

```sh
brew install --cask robbietilton-compositor
```

## 功能特性

### 图层
- 图层与图层组，支持不透明度以及 Photoshop 全套混合模式（顺序一致）——图层组的不透明度会统一减弱组内所有内容
- 图层蒙版：可在画布任意位置（超出图层自身像素范围）绘制、填充、反转、模糊和羽化蒙版；可链接或解除链接以单独变换蒙版
- 剪贴蒙版与图层组蒙版
- 调整图层：色相/饱和度、色阶、曲线、曝光、渐变映射、颗粒、黑白、色彩平衡、反相、高斯模糊、动感模糊和噪点
- 图层样式：描边、投影、颜色叠加、内阴影、外发光和内发光，基于 GPU 渲染，随时可编辑
- 向下合并、合并图层和合并组（⌘E）
- 拖拽即可复制、行内重命名、重排和嵌套图层；按住 Option 拖拽复制；图层面板提供右键菜单
- 复制粘贴整个图层和文件夹（无选区时按 ⌘C/⌘V），可在同一工程内或跨工程进行，也可在工程间拖拽

### 变换
- 非破坏性的移动、缩放、旋转和翻转——无论缩到多小，图像始终保持完整分辨率
- 自由扭曲（⌘ 拖拽控制柄），按住 Shift 锁定轴向
- 同时变换多个图层或整个图层组
- 吸附到画布和图层边缘及中心，并带参考线
- 位置、大小、缩放和角度的精确数值，可用方向键微调
- 水平或垂直翻转图层和翻转画布

### 选区
- 矩形和椭圆选框、自由套索和多边形套索，以及魔棒工具——魔棒按颜色选择，对象工具追踪你点击的内容（Tab 切换）
- 主体选择，以及对任意选区的扩展、收缩和羽化
- 添加或减去选区、移动选区轮廓，或移动和复制选区内的像素
- 将图层像素或蒙版载入为选区
- 内容感知填充，还可将图像扩展到边缘之外

### 绘画与修饰
- 画笔支持大小、硬度、不透明度和平滑度，可在绘制或擦除模式（B 和 E）下使用，按住 Shift 画直线
- 污点修复画笔（内容感知）
- 仿制图章，可对齐或不对齐，可采样单个图层或所有图层
- 模糊工具，可作用于像素或蒙版
- 渐变工具和形状工具（矩形、圆角矩形、椭圆和线条），形状保持可编辑而不会被栅格化
- 文字工具（T）：在可拖动、可调整大小的段落框内进行行内多行编辑；工具头部可设置字体、字号、颜色、对齐和间距；可变换文字并将其用作剪贴蒙版
- 吸管工具和完整的取色器

### 调整与滤镜
- Camera Raw 滤镜：在画布旁的侧面板中提供光线、颜色、曲线、颜色混合器、颜色分级、细节、光学和几何
- 色阶（含自动）、曲线、色相/饱和度、曝光、渐变映射、颗粒、黑白、色彩平衡和反相
- 高斯模糊和动感模糊，可扩散到图层边缘之外
- 添加噪点、暗角、泛光/发光、色调对比、镜头校正和移除背景
- 实时预览，存在选区时仅限选区范围内

### 画布与文件
- 标签页中可打开多个工程
- 命令面板（F）：像 Raycast 或 Obsidian 那样按名称搜索所有菜单命令和工具，用 Return 执行
- 标尺（⌘R）、从标尺拖出的参考线、间距和细分可调的布局网格，以及针对参考线、网格、图层和文档边界的吸附
- 裁剪带吸附，支持 3:4、9:16 等比例，按住 Option 对称裁剪；存在选区时，裁剪从选区开始
- 画布大小、图像大小和裁切
- 缩小时的高质量锐利下采样，放大时的像素网格
- 导入 JPEG、PNG、HEIC、TIFF、SVG、相机 RAW（先进行显影）以及 Photoshop PSD 和 PSB（8 位 RGB；不支持 CMYK）。Photoshop 的图层组、蒙版、混合模式、填充矩形/椭圆以及简单的水平文字保持可编辑；其他矢量对象和竖排文字会转为像素。应用前会显示转换报告。
- 大型文档：内存预算随你的 Mac 扩展，过大的 Photoshop 文件无法打开时，其图层会被裁切到画布范围内
- 导出 JPEG 并带实时预览（⇧⌥⌘S）；合并拷贝
- 工程保存时可继续工作
- 全局采用 Photoshop 风格快捷键，可在「编辑 > 键盘快捷键」中重新映射
- 像 Photoshop 那样，拖动数字标签即可微调数值
- 自动更新，已签名并公证

### 与 AI 智能体协作
- AI 智能体和脚本可直接构建和编辑工程：`.comp` 是一个包含 PNG 图层和一个清单（manifest）的文件夹，打开的工程会随着文件的写入实时更新。参见[编写 Compositor 工程](docs/writing-comp-files.md)

## 环境要求

- 搭载 Apple 芯片的 Mac，macOS 26.0 或更高版本
- Xcode 26 或更高版本（用于从源码构建）

## 构建

打开 `Compositor.xcodeproj`，运行 **Compositor** scheme。

## 发布

`scripts/release.sh` 会构建 Release 版本，用 Developer ID 签名、公证并装订（staple），最后打包成 `dist/Compositor-<version>.dmg`。

它需要以下内容（均不存放在本仓库内）：

- 登录钥匙串中的 **Developer ID Application** 证书
- 通过 `xcrun notarytool store-credentials "compositor-notary" …` 保存的公证凭据
- [`create-dmg`](https://github.com/create-dmg/create-dmg)（`brew install create-dmg`）
